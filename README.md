# Moroccan Used-Car Price Estimator

Predicting fair market price for used cars in Morocco from listing attributes.

**Status:** in development — data collection

## Problem
Buying a used car in Morocco can be challenging because the factors that determine a car's price are not always clear. This project aims to estimate a fair market price based on different listing attributes.


## Stack
Python, LightGBM, FastAPI, Docker, Streamlit
