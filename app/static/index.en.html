How it works

1

LightGBM trained on cleaned public listings, on log-price, so it minimizes percentage error rather than error in absolute dirhams.

2

The range widens automatically when the brand or model can't be identified, because the measured error there is almost twice as large.

3

Median error 13.5% (mean 25.9%) across 22,564 listings, measured against asking prices, not sale prices. No trim or engine version: two Golfs with different trims look like the same car.
